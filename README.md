## 适用于《Forza Horizon 6》的自动拍卖行程序

它会监控拍卖行中你设置好的车辆，一旦出现就立即买断、领取车辆并循环执行。只需设置一次筛选条件，然后让它保持运行即可。热门稀有车辆该工具的买断成功率大约为 10%，且成功率和网络环境也有关。

***

# 功能

- 自动搜索并买断
- 跳过已售出的列表，寻找新的拍卖项
- 自动领取所有成功拍下的车辆
- 小巧的置顶悬浮窗，实时显示状态数据
- 日志页显示启动、购车、失败、跳过等关键事件
- 成功购车时 Windows 通知会显示具体时间
- F8 开始/停止，F9 紧急停止
- 可在达到指定车辆数量或运行分钟数后自动停止
- 智能识别页面，避免误点到其他页面

***

# 要求

- Windows 10 或 11
- PC 版《Forza Horizon 6》
- 推荐 1920 x 1080 全屏；窗口化可使用 **1280 x 720 / Full Screen 关闭 / UI 100 / 16:9 无黑边**。窗口被手动拉伸出或窗口比例与实际比例不一致时产生了黑边，极可能就会识别失败。
- 极低画质预设
- **开启**动态背景（或在配置文件中设为 false）
- UI 缩放设为 **100**
- 游戏语言设为 **English US**（当前模板基于英文 UI；中文 UI 识别需后续单独适配）
- 使用键盘菜单导航（程序使用按键，而不是鼠标）
- 如果你的 Forza 是使用提升权限启动，则需要以管理员身份启动程序（右键 + 以管理员身份运行）
- 强烈建议使用有线以太网

# 设置

## 第 1 步 - 打开拍卖行

启动《Forza Horizon 6》，前往嘉年华站点中的拍卖行。

<img width="1916" height="971" alt="image-1" src="https://github.com/user-attachments/assets/2e4c412e-974e-4bf4-9d4d-bbc31fcd2432" />

***

## 第 2 步 - 配置搜索

打开 **Search Auctions** 并设置筛选条件：

- 想要车辆的 **Make** 和 **Model**
- 将 **Max Buyout** 作为你的安全上限。程序会在不检查价格的情况下购买第一辆匹配车辆，因此这是你每辆车最多可能花费的金额。请谨慎设置。

返回上一层，让屏幕停留在 **Search config** 视图。程序会从这里开始运行。

<img width="1919" height="1079" alt="image" src="https://github.com/user-attachments/assets/7fac68c0-f89d-45ee-a10a-5133b02da681" />

***

## 第 3 步 - 运行程序

双击 **FH6-Sniper.exe**。屏幕左上角会出现一个小悬浮窗。

点击回到 FH6，按 **F8** 或 **开始**，然后让它保持运行。

停止方式：再次按 **F8**，按 **F9** 紧急停止，或点击悬浮窗上的 **停止**。

悬浮窗中的 **日志** 标签页会显示启动、开始蹲守、发现车辆、购车成功、买断失败、车辆售出跳过等关键事件。成功购车仍会写入 `logs/purchases.csv`，Windows 通知会显示本次第几辆以及成功时间。

# 从源码打包

安装依赖后可使用 PyInstaller onedir 方式生成候选 exe：

```powershell
.\scripts\build.ps1
```

构建产物位于 `dist\FH6-Sniper\FH6-Sniper.exe`。正式发布前请先完成游戏内手动测试。

构建脚本会自动运行 exe 自检。如果本地 Python 的 Tkinter/Tcl 安装不完整，请换用带 Tkinter 的官方 Python，或指定解释器：

```powershell
.\scripts\build.ps1 -PythonExe "C:\Path\To\python.exe" -RecreateVenv
```

也可以在 GitHub Actions 中手动运行 **Build Windows EXE** workflow，生成可下载的候选构建产物。

如需在打包前额外运行源码自检，可加上 `-SourceSelfTest`；常规 CI 会自动执行源码编译和轻量烟雾测试。

# 设置项

程序开箱即可使用。如果你想进行调整，请打开 **设置**：

- **max\_cars** - 获胜达到该数量后自动停止（默认：1）
- **max\_minutes** - 运行达到该分钟数后自动停止（默认：180）
- **collect\_after\_buyout** - 如果你希望手动领取车辆，请设为 `false`
- **notify\_sound** / **notify\_toast** - 关闭获胜提示音或通知弹窗
- **buyout\_select\_delay\_ms** - 在选择 Buy Out 与按 Enter 之间额外等待的毫秒数。如果程序偶尔打开 Place Bid 对话框而不是 Buy Out，可以调到 `200`（默认：0）
- **buyout\_dialog\_timeout\_s** - 按下 Enter 后等待 Buy Out 确认框出现的秒数。如果网络或菜单加载较慢，可以调到 `2.5` 或更高（默认：2.5）
- **moving\_background** - 如果你已在 FH6 中**关闭**动态背景视频设置，请设为 `false`（默认：true）
- **win32\_api\_input** - 后台按键模式。开启后程序会把按键消息发给 FH6 窗口，切出游戏时不会因为“未聚焦”暂停；它只负责输入，不负责遮挡后的画面识别（默认：false）
- **window\_content\_capture** - 实验性后台窗口捕获（遮挡识别）。开启后会优先尝试按窗口句柄捕获 FH6 画面，被其他窗口遮挡时有机会继续识别；它只负责画面捕获，不负责后台按键（默认：false）
- **overlay\_capturable** - 允许截图/录制捕获悬浮窗。排查截图时可开启；平时建议关闭，避免悬浮窗遮挡识别区域（默认：false）

# 备注

- 默认模式下只会在 FH6 是当前聚焦窗口时运行。如果你切出游戏，悬浮窗会显示 **暂停：FH6 未聚焦**。点击回到游戏即可继续。
- 如需切出游戏后继续运行，可在悬浮窗 **设置 > 后台模式** 中开启 **后台按键模式（窗口需可见）**。
- 如需真正后台运行，建议同时开启 **后台按键模式（窗口需可见）** 和 **实验性后台窗口捕获（遮挡识别）**：前者负责给 FH6 发按键，后者负责在窗口被遮挡时读取 FH6 画面。只开启实验性后台窗口捕获时，切出 FH6 仍会被默认聚焦保护暂停。最小化 FH6 不保证可用。
- 悬浮窗默认会从屏幕录制/截图中隐藏，因此你可以把它放在屏幕任意位置；排查问题时可临时开启 **允许截图/录制捕获悬浮窗**。
- 点击并按住标题栏即可拖动悬浮窗。
- 你不会赢下每一次狙击。和其他工具一样，程序受限于 FH6 的菜单动画和拍卖服务器响应。
- 如果服务器很慢或过载，可能会导致超时或恢复失败；可适当增加买断确认等待时间，或重启 FH6 和程序后再试。
- **日志** 标签页只保留最近约 200 条关键事件；完整排查信息仍以 `logs/sniper.log` 为准。

# 故障排查

**悬浮窗显示“暂停：FH6 未聚焦”** - 默认输入模式下 FH6 不是当前聚焦窗口。请点击回到游戏；如果你想切出游戏后继续运行，请开启 **后台按键模式（窗口需可见）**。

**F8 没有任何反应** - 你电脑上的另一个应用可能拦截了 F8 键。关闭它，或在 `config.json` 中修改热键。

**程序漏判某个画面并卡在那里** - 重启 FH6 和程序。确保画质预设为 **Very Low**，语言为 **English US**，UI 缩放为 **100**，画面为 **16:9 且无黑边**。窗口化时推荐 **1280 x 720**；如果窗口被遮挡，请尝试开启 **实验性后台窗口捕获（遮挡识别）**。

**程序打开了 Buy Out 对话框，但不会点击 Yes。** <img width="1513" height="840" alt="image" src="https://github.com/user-attachments/assets/61472f11-389c-47f9-90e3-197530331486" />

这几乎总是因为 FH6 的 **Moving Background** 视频设置与程序中的设置不匹配。如果你在游戏内关闭了动态背景，请打开悬浮窗中的 **设置** 标签页，并取消勾选 **动态背景模式（FH6 视频）**，这样程序就会为你的设置加载正确的模板。

  <img width="331" height="472" alt="image" src="https://github.com/user-attachments/assets/049c4dab-a718-4cab-882e-d45782f5391c" />

**程序在点击“开始”后马上显示“已停止：无法恢复”。**

两个常见原因：

- **画面不符合当前模板。** 请检查 FH6 是否为 **English US**、16:9 无黑边、UI 100、动态背景设置匹配，以及窗口是否被遮挡或最小化。程序模板目前只能匹配英文 UI。
- **可被截屏捕获的悬浮窗遮住了菜单。** 如果你启用了 **允许截图/录制捕获悬浮窗**，悬浮窗可能会落在程序正在读取的区域上方。把它拖到右上角或右下角，避免遮挡游戏 UI。
